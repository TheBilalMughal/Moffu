# Localization and Responsive Web

## i18n
Separate UI locale, org default language, user preference, review/reviewer language, AI reply language, legal locale and source/provider language. Stable machine keys never translated. BCP-47 locales, IANA timezones, locale-aware Intl formatting; language never determines currency/timezone/jurisdiction.

Public localized SEO routes only when genuinely translated. Private portals remain noindex. All UI/error/a11y/email/notification strings localizable. Customer/provider content is not silently translated. AI reply language follows Brand Brain/reviewer rules, not portal locale. Roman Urdu/mixed language supported when configured. RTL architecture-ready but not claimed supported until QA.

## Responsive V1
No native mobile app, push or advanced PWA/offline claims. Customer-critical flows must work on mobile/tablet/desktop. Admin may optimize dense workflows for desktop while staying safe/readable on mobile. No hover-only required actions. Mobile Reviews uses list -> detail; tables adapt to prioritized cards/columns. Airline-style date picker becomes mobile sheet/full-width/single calendar.
