# Customer Portal

## Navigation
Dashboard; Reviews (All/Pending/Replied/Needs Attention/History); AI Agent (Brand Brain/Rules/Languages/Test Agent); Locations; Reports; Team; Billing; Integrations; Notifications; Settings.

## Dashboard
Actionable Google status, active locations, reviews needing attention/awaiting reply/replied/sensitive and recent activity. No decorative/fake KPIs.

## Reviews
Desktop split list/detail; mobile list -> detail. Server-side filters: location, brand, rating, workflow, risk, language, date, provider and policy-safe search. Draft editor supports edit/regenerate/approve/publish with stale/risk states. Regenerate options can include shorter/warmer/professional/less formal/different/custom.

## Team/settings
Invites have role/location scope, expiry/revoke/resend. Org country/timezone/currency, ownership transfer, destructive confirmations. Google page shows masked connection status/locations/last sync/reconnect/disconnect. Security, notifications, privacy/data and support are real workflows.

## Reports
Overview, review activity, response activity/time, rating distribution, AI usage/acceptance/edit rate, location/language; metrics follow registry and provider-policy limits.
