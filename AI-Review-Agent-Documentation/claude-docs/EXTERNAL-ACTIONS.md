# External Actions

These cannot be marked complete from code alone:
- Final production domains/DNS and environment variables.
- Supabase production project/plan and verified backup/PITR/object-storage capabilities.
- Google Cloud OAuth consent/configuration, GBP API access/production approval and current policy verification.
- Resend sending domain plus SPF/DKIM/DMARC verification.
- Billing provider production account, products/prices mapping as configured, webhook secrets/endpoints, payment-method capability, tax/business/entity details.
- Final pricing/plan/add-on values and market configuration.
- Legal review of Terms/Privacy/Cookies, jurisdictional rights, retention/legal-hold periods, governing law and tax treatment.
- Product analytics production project/config and privacy/consent review.
- Production monitoring/alerting credentials and routing.
- Backup/restore configuration, documented RPO/RTO and successful restore test.
- Any Google/Stripe/Resend/Supabase or other provider approval/configuration required by current docs.

Each item must carry evidence before status becomes CONFIGURED/COMPLETED.
