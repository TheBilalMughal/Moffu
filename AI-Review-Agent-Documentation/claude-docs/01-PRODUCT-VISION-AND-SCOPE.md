# Product Vision and Scope

## Positioning
**Brand-trained AI reputation agent, not a generic AI reply generator.** External LLMs are shared infrastructure; each merchant has a persistent structured Brand Brain containing voice, rules, language behavior, examples and confirmed preferences.

## V1 outcome
Website -> Sign up -> verify email -> create organization -> country/timezone -> connect Google -> select locations -> build Brand Brain -> test with synthetic review -> dashboard -> reviews -> generate/edit/approve/publish -> history/reports.

## In scope
Google Business Profile, multi-location organizations, customer/team RBAC, internal Admin, billing architecture, notifications/email, support, privacy/legal/consent, analytics, rate limits, i18n-ready responsive web, backups/DR.

## Out of V1
Facebook/Instagram integrations, native mobile apps, push notifications, advanced PWA/offline, proprietary/self-hosted LLM, public API, automatic bulk publishing, session replay/heatmaps, agency UI unless explicitly activated.
