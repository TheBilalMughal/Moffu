# Implementation Plan

Recommended dependency-aware milestones:
1. Repository/workspaces, shared contracts/design tokens, env validation, Supabase foundation.
2. Core schema, reference IDs, auth/profile/org/membership, RLS and RBAC.
3. Onboarding persistence and readiness derivation.
4. Google OAuth, locations, sync and review workflow foundation.
5. Brand Brain, AI provider abstraction, risk/validation and draft lifecycle.
6. Customer Reviews/Dashboard/Locations/Brand Brain/Team/Settings.
7. Internal Admin, search, org 360, platform RBAC and operational tooling.
8. Durable jobs, notifications, Resend email.
9. Billing/plans/add-ons/usage/provider integration.
10. Storage, support, exports/imports.
11. Privacy/legal/consent/data rights.
12. Analytics/reporting/rate limits/i18n/responsive hardening.
13. Public website/SEO/pricing/help/legal pages.
14. Security/E2E/visual QA/performance/observability.
15. Backup/DR verification, external approvals/configuration and launch readiness.

This order is guidance, not a reason to ignore user-requested work. Resolve prerequisites automatically and never invent blocked business/legal/provider decisions.
