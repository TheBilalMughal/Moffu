# UI/UX Design System

## Visual direction
Primary `#0D4C3C`, light-first, white/off-white/neutrals, charcoal text, subtle borders and restrained shadows. Modern sans (Inter/comparable). Marketing spacious, customer guided/content-first, Admin dense/operational.

No pill/capsule language, emoji icons, colorful icon tiles, sparkle/robot/brain imagery, glowing AI orbs, purple/blue AI gradients, glassmorphism or decorative “AI SaaS” clutter. One restrained outline icon family.

## Components
Central primitives: Button/Input/Textarea/Select/Checkbox/Radio/Switch/Badge/Avatar/Tooltip/Popover/Dropdown/Modal/Drawer/Tabs/Table/Pagination/Breadcrumb/Alert/Toast/Skeleton/EmptyState/StatCard/PageHeader/FilterBar. Domain components include ReviewCard/Detail, AIDraftEditor, RiskBadge, BrandBrainForm, GoogleConnectionCard, PlanCard, UsageMeter, AddonSelector.

## Interaction
Purposeful 150-300ms motion, reduced-motion support. Airline-style compact filters and DateRangePicker. Intentional loading/empty/error/403/404/500. Unsaved-change protection. Optimistic updates only where safe; never Google publish, finance or permissions. Accessibility, keyboard, responsive and touch QA mandatory.
