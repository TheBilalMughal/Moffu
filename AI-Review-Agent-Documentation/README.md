# AI Review Agent - Documentation Pack

This package is the canonical product and implementation documentation for the AI Review Agent SaaS.

- `claude-docs/` is optimized for Claude implementation: compact, self-routing, low repetition and status-driven.
- `developer-docs/` explains the architecture, flows, failure handling and maintenance expectations for human developers.
- `EXECUTIVE-SUMMARY.md` is a concise product/technology overview suitable for a developer, technical stakeholder or investor.

The product positioning is: **Brand-trained AI reputation agent, not a generic AI reply generator.** Businesses connect Google Business Profile, configure a persistent Brand Brain, receive brand-aware AI reply drafts, review/edit/approve them, and publish through a controlled backend workflow.
